# NCurator-Desktop AI 术语表

- `Main Graph`
  - 系统编排层，负责 intent、context、plan、dispatch、synthesis 与 run 收尾。
- `Human Subgraph`
  - 单任务执行层，负责 brain 决策循环与正式交付生成。
- `Human Response`
  - human 的交付节点，负责生成 `deliveryMarkdown`，并在需要时发最终答复流。
- `Direct Human`
  - 无需 plan 时，由单个 human 直接完成用户请求并输出最终答复的路径。
- `Synthesis Human`
  - plan 业务任务全部结束后，由 runtime 追加的最终汇总 human。
- `Task Delivery`
  - 某个 human 任务完成后生成的正式交付物；真相源字段是 `deliveryMarkdown`。
- `Handoff Markdown`
  - 任务间自然语言交接文档；优先用于 plan 子任务之间的依赖传递。
- `Delivery Markdown`
  - 统一任务交付文本。对于中间任务，它是 handoff；对于 direct/synthesis，它同时是最终答复。
- `Skill Card`
  - 暴露给 human brain 的轻量能力卡片，不等于完整 skill 内容。
- `Capability`
  - 一组同类工具实现的目录与能力边界。
- `Tool`
  - 供 human 原子调用的具体执行单元。
- `Draft Review`
  - AI 编辑后生成的待审阅结果集合，不直接等于真实文件写回。
- `Pure Search`
  - 不进入 AI graph 的本地检索模式。
- `Canonical Doc`
  - 当前默认真相源文档；不是历史记录，也不是临时设计稿。
- `Code Truth Source`
  - 文档缺失或漂移时应核对的最终代码入口。
