# Settings PRD

## 1. 产品目标

- 用户在设置页完成模型配置、工作地址与网页资料管理，以及本地／远程向量模型管理；设置项变更即时保存并对后续 workbench 与 AI 运行稳定生效。

## 2. 范围

- 包含大模型可用服务配置的新增、编辑、删除，预设服务商与自定义配置两种形态。
- 包含工作地址的添加、包含检测、索引检查、索引更新、查看和移除。
- 包含全局网页资料的添加、检查更新、索引更新、打开和删除。
- 包含本地／远程向量模型的分类列表、本地下载、远程配置与测试、当前模型选择、索引失效提示与手动重建入口。
- 包含设置页左侧栏中的官方使用帮助入口。
- 包含按伙伴、目录与截止日期清理运行缓存及文件修改历史。

## 3. 术语

- 大模型配置：一条可供 workbench 使用的模型连接配置，包含预设服务商配置与自定义配置两种形态。
- 预设服务商配置：选择内置服务商并填写 API Key 创建的配置，名称固定为服务商名，地址由应用维护，同服务商仅一条。
- 自定义配置：用户完整填写名称、服务地址和 API Key 的配置。
- 工作空间：设置页中「文件地址森林 + 全局网页资料」的管理区域。
- 工作地址：一条本地目录根路径，同一路径不重复添加，不另设名称。
- 检查更新：读取当前真实数据，判断哪些文件或网页需要重新建立索引。
- 更新索引：处理可索引、失败或模型不匹配的资料，把内容写入后续检索可用的本地索引。
- 网页资料：全局共享，由 URL 导入并抓取，同一规范化 URL 不重复添加。
- 向量模型：索引使用的本地或远程嵌入模型；全部 KB 搜索及资料列表统一要求当前模型可用、已有有效索引身份匹配。
- 索引失效：有效资料使用的模型身份与当前选择不匹配。模型切换不重建；用户在工作空间手动重建，或切回仍完整匹配的模型。

## 4. 需求明细

### 4.1 通用设置

#### SET-GENERAL-001 AI 运行系统通知

- 系统行为：通用设置默认开启 AI 运行终态通知。AI 运行成功、失败、取消以及应用启动时恢复为失败的中断任务，均发送一次电脑系统通知；等待审批不发送通知。通知展示馆长 logo，内容只包含状态提示，不展示 AI 输出正文。
- 系统行为：点击系统通知后恢复应用窗口，并打开对应伙伴。关闭开关后不发送系统通知，但不影响 AI 运行和页面内状态。
- 验收：`SET-GENERAL-001-AC1` 默认开启；`SET-GENERAL-001-AC2` 四类终态各发送一次；`SET-GENERAL-001-AC3` 关闭后静默；`SET-GENERAL-001-AC4` 点击通知打开对应伙伴；`SET-GENERAL-001-AC5` 系统通知不可用时应用不崩溃；`SET-GENERAL-001-AC6` 通知展示馆长 logo。

#### SET-GENERAL-002 设置页窗口层与操作区

- 系统行为：Windows 设置页的原生窗口控制层独立位于业务内容上方；业务拖动区不遮挡侧栏、返回和页面操作按钮。非 Windows 平台保留页面顶部拖动区。
- 验收：
  - `SET-GENERAL-002-AC1` Windows 原生标题栏高度为 36px，业务内容从标题栏下方开始，页面按钮区不落入原生控制层。
  - `SET-GENERAL-002-AC2` 设置页主内容和侧栏拖动区可命中，侧栏折叠/展开按钮为 `no-drag` 且仍可操作。
  - `SET-GENERAL-002-AC3` 各设置页使用居中且统一限宽的内容（与大模型页一致）、简洁页头和分组面板；通用页按「应用偏好」（语言、官方服务线路、AI 完成通知）和「数据与诊断」（错误日志、伙伴缓存）组织。中英文说明及操作在窄窗口完整可见，树和列表仍可独立滚动。

#### SET-GENERAL-003 错误日志入口

- 系统行为：应用遇到索引、向量模型、知识库、AI 运行，以及后台或界面的未捕获错误时，自动写入用户数据目录的 `logs/app.log`。日志只记录错误，单文件最多 2MB，超出后保留最新内容。日志包含时间、应用版本、系统信息、错误模块、必要上下文、错误信息和堆栈。
- 隐私边界：日志不得记录 API Key、聊天正文、模型回答、文件正文或完整绝对路径；索引错误只记录文件名或工作地址相对路径。
- 系统行为：通用设置展示“错误日志”说明和带统一 `BsFolder2Open` 文件夹图标的“打开”按钮。点击后打开日志目录；目录不存在时自动创建。用户可将 `app.log` 发给作者排查问题。
- 验收：`SET-GENERAL-003-AC1` 发生已捕获错误后生成或追加 `app.log`；`SET-GENERAL-003-AC2` 日志遵守隐私边界和 2MB 上限；`SET-GENERAL-003-AC3` 点击按钮会打开日志目录。

#### SET-GENERAL-004 清理伙伴的缓存数据

- 系统行为：通用设置展示「伙伴缓存」及「管理缓存」，打开 680px 弹框。选择伙伴（支持全部伙伴）、勾选临时脚本、工具结果、附件与临时资源、文件修改历史、选择截止日期后，展示按日期和类型汇总的待清理数量及占用空间。默认当前伙伴、四类目录、当天日期；每次打开按当天重置截止日期。伙伴选中项与下拉项显示对应形状、颜色的小人头像及工作台同款动画，「全部伙伴」显示群组图标。弹框适配窗口高度，标题与底部汇总固定，筛选区紧凑排列，待清理列表独立滚动，小高度窗口允许内容区滚动。列表从旧到新，无逐文件列表或版本预览。
- 目录说明：临时脚本为 AI 执行任务时编写的临时脚本；工具结果为过长工具输出的完整文本；附件与临时资源为粘贴附件、读图缓存、文档渲染图片及网页截图；文件修改历史为修改前备份与差异预览，清理后无法回退。每行使用统一 `BsFolder2Open` 文件夹图标打开所选伙伴对应的完整目录，不受勾选或日期影响；全部伙伴时禁用，目录不存在提示暂无数据，不创建空目录。
- 时间规则：脚本/工具结果/资源按最后更新时间，互相依赖的产物按组内最新时间；修改历史按该次修改发生时间，整条记录和资源一起清理。截止日期取当天 00:00，严格删除早于截止时间的数据；快捷选择只提供「7 天前」「30 天前」，允许选择明天以清理今天的数据。
- 范围说明：「清理所选目录中截止日期前的数据。伙伴、聊天记录和工作目录文件等不会被删除。」只清理所选伙伴的对应缓存与修改历史，不回退实际文件，不触碰模型、索引、配置和未选伙伴。草稿正在使用的附件自动跳过；未选或未到截止时间的修改历史完整保留。运行、提交、收尾、清理中的伙伴不能再次清理；清理期间拒绝新任务。
- 统计反馈：分类行显示所选伙伴各目录的实际总占用，不受截止日期或目录勾选影响；待清理列表及底部预计释放只计算当前日期和勾选范围内可清理的数据。统计中显示「统计中」，读取失败显示错误，不能以 0 B 代替；空状态区分没有缓存、已有缓存但不符合筛选条件、未选择清理内容。日期与数量使用完整文案，不拼接粘连。
- 清理前显示确认窗口，说明范围、空间和不可恢复性；关闭、取消、Escape、遮罩均无副作用。执行期间禁用重复确认及取消，失败保留确认框并显示错误以便重试。执行前再次检查时间、草稿附件、运行状态和清理范围，不跟随符号链接。完成刷新预览并报告释放空间；部分失败如实反馈，保留可重试状态。
- 验收：
  - `SET-GENERAL-004-AC1` 入口、弹框标题和范围说明使用上述文案。
  - `SET-GENERAL-004-AC2` 伙伴及四类目录可选，伙伴头像与动画一致，说明可见，无逐文件列表。
  - `SET-GENERAL-004-AC3` 默认当天，7/30 天前快捷选项改变预览，仅清理严格早于截止时间的数据。
  - `SET-GENERAL-004-AC4` 总占用不随筛选变化，待清理汇总从旧到新，数量/空间/总计一致；统计中、失败与不同空状态可区分，无候选时禁用清理。
  - `SET-GENERAL-004-AC5` 文件夹图标打开正确目录；全部伙伴时禁用，缺失目录提示暂无数据。
  - `SET-GENERAL-004-AC6` 清理先确认，取消不删除；完成后刷新并报告释放空间。
  - `SET-GENERAL-004-AC7` 伙伴、聊天记录、配置、工作目录文件及未选伙伴数据保留。
  - `SET-GENERAL-004-AC8` 修改记录、备份与审核材料同步清理，保留时仍能精确回退。
  - `SET-GENERAL-004-AC9` 运行与清理互斥，草稿附件自动跳过；未选或未到截止时间的修改历史完整保留。
  - `SET-GENERAL-004-AC10` 无效范围、符号链接和文件变化不造成越界删除；失败可重试且如实反馈。

#### SET-GENERAL-005 界面语言

- 系统行为：提供「跟随系统」「简体中文」「English」，默认跟随系统。匹配电脑首选语言列表中的已支持语言，无匹配时使用英文。设置即时保存，重启后统一生效，不强制打断运行中的任务；保存后明确提示重启生效。
- 中文界面品牌为「馆长」，英文界面为「NCurator」。页面、编辑器、菜单、业务提示和系统通知使用同一有效语言；聊天正文、AI 输出和用户内容不自动翻译。语言不改变服务线路、安装名称和更新渠道。
- 验收：`SET-GENERAL-005-AC1` 三个选项及默认行为正确；`SET-GENERAL-005-AC2` 保存、重启和升级后保留偏好；`SET-GENERAL-005-AC3` 生效范围包含通用组件和通知；`SET-GENERAL-005-AC4` 中文与英文布局可用，语言与线路独立。

#### SET-GENERAL-006 官方服务线路

- 系统行为：只提供「中国大陆」「国际」。没有有效配置时根据发行包初始化并保存：国内包为中国大陆，国际包为国际，无法识别发行标识时为中国大陆。已有有效配置不被重启、升级或重新识别发行包覆盖。
- 用户手动切换后即时保存，后续官方服务操作使用新线路，在途请求保持原入口。请求失败及重试不自动跨线路切换。设置不影响用户配置的模型地址，不改变固定的应用更新渠道。
- 验收：`SET-GENERAL-006-AC1` 只有两个选项且初始化正确；`SET-GENERAL-006-AC2` 手动值持久化，更新其他设置不覆盖；`SET-GENERAL-006-AC3` 新请求切换、在途请求固定、失败不换线；`SET-GENERAL-006-AC4` 界面语言与自动更新渠道独立。

### 4.2 大模型配置

#### 概念

- **预设服务商**：应用内置 DeepSeek、通义千问、小米 MiMo、智谱 GLM 四家接入信息；名称和地址由应用维护，同服务商只允许一条配置。本页管理服务连接，模型目录的选择与反馈见 Workbench 的 `WB-COMPOSER-007`。
- **自定义配置**：由用户填写名称、服务地址和 API Key 的配置，名称不可与其他配置重复。
- 预设配置以应用维护的服务商名称与地址识别；名称或地址不匹配时按自定义配置展示。

#### SET-MODEL-001 页面加载与配置列表展示

- 系统行为：进入大模型页后自动拉取全部配置。该页面只管理可用服务，不维护默认、启用或当前状态。配置列表展示服务商图标与配置名称；自定义配置在名称旁展示「自定义」标签。
- 验收：
  - `SET-MODEL-001-AC1` 页面打开后可见配置列表，而不是停留在未初始化状态。
  - `SET-MODEL-001-AC2` 配置列表展示服务商图标、配置名称和脱敏后的 API Key。
  - `SET-MODEL-001-AC3` 自定义配置名称旁展示「自定义」标签，预设配置不展示该标签。

#### SET-MODEL-002 新增与编辑配置

- 系统行为：新增和编辑共用同一弹框，表单依次为类型（推荐 / 自定义）、服务商或名称与地址、API Key。新增默认选中「推荐」；编辑默认落在当前配置所属类型。
  - 推荐类型：通过纯下拉选择预设服务商，选项带图标与名称；已配置服务商禁用并标注「已配置」；不展示名称输入框，配置名称由应用固定为服务商名，地址固定为目录默认地址，只要求填写 API Key。编辑推荐配置时服务商下拉可改，改为其他服务商保存后仍为推荐类型。
  - 自定义类型：填写名称、模型服务地址和 API Key；名称不得与现有配置重复。
  - 保存前校验必填字段；弹框点击遮罩区域时保持打开，避免误触丢失输入。
- 验收：
  - `SET-MODEL-002-AC1` 新增弹框存在「类型（推荐 / 自定义）」单选且默认推荐；推荐类型无名称输入框，只要求下拉选择服务商并填写 API Key。
  - `SET-MODEL-002-AC2` 保存推荐配置后名称等于服务商名、地址为目录默认地址，同服务商只存在一条配置；已配置服务商在下拉中禁用并标注「已配置」。
  - `SET-MODEL-002-AC3` 自定义类型可填写名称、地址和 API Key；名称重复时保存被拦截。
  - `SET-MODEL-002-AC4` 编辑推荐配置服务商下拉可改，改为其他服务商保存后仍为推荐类型且未新增记录；编辑自定义配置带出当前完整值。
  - `SET-MODEL-002-AC5` 必填字段不完整时，保存不会提交。
  - `SET-MODEL-002-AC6` 新增、编辑弹框点击遮罩区域时保持打开，用户输入不会因误触丢失；用户仍可通过取消或完成操作退出。

#### SET-MODEL-003 删除配置

- 系统行为：删除配置后刷新列表并移除对应记录。
- 验收：
  - `SET-MODEL-003-AC1` 删除成功后，该配置不再出现在列表中。
  - `SET-MODEL-003-AC2` 删除失败时，界面会给出明确错误提示。

### 4.3 工作地址

设置页「工作空间」管理文件地址森林与全局网页资料。用户直接添加目录；树的顶层节点就是各地址。网页资料是全局一份，与文件地址并列。

#### SET-WORKSPACE-001 页面加载

- 系统行为：进入工作空间页后自动拉取全部文件地址，详情区使用 `文件 / 网页` 两个 tab。文件 tab 展示全部地址组成的目录森林；网页 tab 展示全局网页列表。
- 验收：
  - `SET-WORKSPACE-001-AC1` 页面打开后，文件地址树和网页 tab 会完成初始化，而不是依赖手动刷新。

#### SET-WORKSPACE-006 添加与移除文件地址

- 系统行为：文件 tab 只支持添加目录作为工作地址。候选路径已存在、或已落在现有地址内时，弹窗提示原因并拒绝；若新地址是现有地址的父路径，自动用父路径替换被包含的子根（不二次确认）。添加成功后立即保存并开始后台扫描；扫描结束后左侧可索引数与目录树状态同步刷新。目录树顶层即各地址，可先读取首层，扫描进度独立显示。
- 验收：
  - `SET-WORKSPACE-006-AC1` 点击添加目录后，可为资料范围新增一条工作地址。
  - `SET-WORKSPACE-006-AC2` 移除成功后，该地址从树中消失，其本地资料不会继续出现在后续资料范围选择里。
  - `SET-WORKSPACE-006-AC4` 添加地址后立即开始后台扫描，页面可见扫描进度；用户无需等待扫描完成即可看到顶层首层；扫描结束后左侧可索引数自动更新。
  - `SET-WORKSPACE-006-AC5` 候选路径已存在时弹窗提示「目录已添加」并拒绝；候选是现有地址的子路径时弹窗提示「目录已包含」并拒绝；候选包含现有子根时，父路径自动替换这些子根。

#### SET-WORKSPACE-007 空态与无文件提示

- 系统行为：无文件地址时展示空态；某个地址没有可显示文件时该地址节点展示局部空态。
- 验收：
  - `SET-WORKSPACE-007-AC1` 没有文件地址时，详情区不是空白页，而是明确提示还没有文件地址。
  - `SET-WORKSPACE-007-AC2` 某个地址没有可显示文件时，该地址节点显示明确局部空态。

### 4.4 本地文件视图与文件/网页分区

目录树刷新契约：进入工作空间页时读取一次全部文件地址的顶层；检查运行期间不重载目录树、不清空已显示节点；任务进入成功、失败或取消终态后，对当前已展示的目录层级刷新索引状态，保留展开/折叠，不把已折叠地址重新全部展开。手动点目录树刷新同样只更新已展示节点状态，不重置展开。扫描总数未知时显示活动状态，不显示静态 0% 进度。

更新索引逐文件处理期间只更新进度，不反复刷新目录树；任务终态统一刷新一次目录树和摘要。刷新期间保留旧节点与展开状态；连续操作的旧结果不能覆盖当前目录或当前加载状态。

左侧索引数字对全部文件地址合计：可索引数 = 全部地址的待索引与失败文件之和。

#### SET-WORKSPACE-003 检查目录变化

  - `SET-WEB-004-AC13` 确认停止时正在抓取或索引、尚未写完的网页不落成已索引；当前一小批处理结束即停。
  - `SET-WEB-004-AC14` 确认框仍打开时任务已到成功或失败终态，再点「停止」保持原任务终态，不回退已索引网页。

#### SET-WEB-005 列表项信息、外链打开与删除

- 系统行为：网页列表项展示标题、URL、状态和抓取时间；点击“打开”用系统浏览器打开；删除后刷新全局列表。
- 验收：
  - `SET-WEB-005-AC1` 列表项展示标题、URL、状态和抓取时间。
  - `SET-WEB-005-AC2` 点击“打开”后，用系统浏览器打开原网页，而不是进入本地文档预览。
  - `SET-WEB-005-AC3` 删除成功后，该网页资料从列表中消失。

### 4.6 向量模型管理

本地 Jina 模型只由用户主动下载或恢复已有下载任务，知识库与索引不隐式下载。删除当前本地模型后，依赖嵌入的操作提示不可用，不终止聊天；关键词检索、资料列表及已有正文仍可用。重新安装或主动选择可用远程模型后恢复嵌入能力。工作地址与向量模型配置不阻止普通 AI 任务启动。

#### SET-VECTOR-001 模型列表加载

- 系统行为：进入向量模型页后自动拉取列表，在同一页面按「本地模型」「远程模型」分类展示，不拆成互斥 tab。本地保留 Jina 的名称、说明、标签、安装与下载状态；远程展示配置名称及模型名，两类均标识当前使用模型。远程新增、编辑及操作在本页完成。
- 验收：
  - `SET-VECTOR-001-AC1` 模型列表加载成功后，可区分已安装模型与可下载模型。
  - `SET-VECTOR-001-AC2` 获取模型列表失败时，页面给出明确错误提示。
  - `SET-VECTOR-001-AC3` 本地和远程分类在同页可见，远程空列表仍有新增入口，当前模型标识与实际选择一致。

#### SET-VECTOR-002 单任务下载与进度显示

- 系统行为：同一时间只允许一个下载任务进行；下载过程中展示百分比、当前文件和文件完成数。下载使用用户选定或默认的下载源（当前可选 ModelScope 镜像与 HuggingFace 镜像），同一下载任务全程使用同一源，不会自动切换。
- 验收：
  - `SET-VECTOR-002-AC1` 已有下载任务时，其他模型的下载入口不可继续触发新任务。
  - `SET-VECTOR-002-AC2` 下载过程中，界面持续更新当前文件、完成数和总进度。
  - `SET-VECTOR-002-AC3` 离开向量模型页面不会中断下载；再次进入页面时恢复当前文件、完成数和总进度。
  - `SET-VECTOR-002-AC4` 应用启动时若存在进行中的下载快照，后台自动恢复任务，页面展示恢复后的进度，并沿用快照中的下载源。

#### SET-VECTOR-003 下载完成与错误收敛

- 系统行为：下载完成后自动刷新列表并切换到已安装状态；下载失败时记录错误并给出反馈，同时提供更换下载源重新下载的入口。下载失败后残留的未完成文件会被清理，更换源后的重新下载为完整下载。
- 验收：
  - `SET-VECTOR-003-AC1` 下载完成后，对应模型显示为“已安装”，不再显示下载按钮。
  - `SET-VECTOR-003-AC2` 下载失败时，界面提示失败原因，并退出下载中状态。
  - `SET-VECTOR-003-AC3` 下载失败后，失败提示区域展示“更换源下载”入口。
  - `SET-VECTOR-003-AC4` 点击“更换源下载”后弹出源选择对话框，列出全部可选下载源并标注最近失败的源；确认选择后从该源重新完整下载。
  - `SET-VECTOR-003-AC5` 取消源选择时保持失败状态，不触发重新下载。
  - `SET-VECTOR-003-AC6` 下载失败不会自动切换到其他源；换源只由用户主动选择触发。

#### SET-VECTOR-004 本地模型删除确认与反馈

- 系统行为：已安装模型或下载中的模型均可点击“删除”：删除前先显示确认提示；确认后取消进行中的下载并移除本应用模型目录中的已下载文件；取消确认时保持原状态。模型不跨安装复用，删除后重新下载为完整下载。
- 验收：
  - `SET-VECTOR-004-AC1` 用户确认删除且删除成功后，模型回到可下载状态。
  - `SET-VECTOR-004-AC2` 删除失败时页面提示失败原因，并保持已安装状态。
  - `SET-VECTOR-004-AC3` 点击删除入口后先出现确认弹框，不立即执行删除。
  - `SET-VECTOR-004-AC4` 取消确认后不执行删除，也不进入成功或失败结果态。
  - `SET-VECTOR-004-AC5` 下载中的模型同样提供删除入口；确认后取消当前下载、移除已下载文件，模型回到可下载状态。
  - `SET-VECTOR-004-AC6` 下载中删除成功不提示“下载失败”等错误信息；确认弹框说明删除将取消当前下载。
  - `SET-VECTOR-004-AC7` 删除成功后重新点击下载，必须为真实完整下载，而非复用其他位置的模型副本。

#### SET-VECTOR-005 远程模型配置与测试

- 用户操作：在向量模型页内新增或编辑远程配置，填写显示名称、API 地址、Embedding 模型名称、API Key，并可填写官方单段最大输入 tokens；支持 OpenAI 兼容的 embeddings 接口。未填写及旧配置缺失时统一使用 512 tokens，不根据模型名自动调高；用户明确填写官方上限后才使用该值。保存配置不自动选为当前模型，测试不保存配置、不切换当前模型、不启动资料重嵌。
- 系统行为：测试实际请求输入中的服务与模型，成功显示返回维度，失败显示可理解的错误。远程请求被拒绝时，在 HTTP 状态之外显示有长度限制且已脱敏的结构化服务端原因，不显示原始响应、密钥或请求正文；短文本连接测试不代表实际资料长度符合模型限制。编辑时保留已保存 Key，留空表示不更换；输入新 Key 才替换。Key 由用户在 Renderer 输入并提交，保存后的列表、编辑回填及操作结果只返回是否已配置，不回传原始 Key；错误及日志不得泄露 Key。
- 删除远程配置后刷新列表；当前使用的远程模型须先切换至其他模型才能删除，不自动回退至本地或另一远程模型。删除配置不删除资料正文或扩大索引范围。
- 输入预算：用户只填写官方总上限，程序自动预留特殊 token 和安全余量，并显示预留及可用正文预算。通用兼容接口不保证返回分词器或输入上限，不能以模型列表或短文本测试推断；缺少精确分词器时采用保守长度估算，实际限制仍以服务端为准。超长资料自动进一步切分并保留全文和来源位置，不静默截断；查询文本超限则明确提示缩短，不发送已知超限请求。
- 验收：
  - `SET-VECTOR-005-AC1` 同页完成新增、编辑及删除；名称、地址和模型名校验失败时保留输入并显示错误。
  - `SET-VECTOR-005-AC2` 测试成功显示维度，鉴权、网络及响应格式错误明确反馈；测试不改变当前模型、配置列表或资料索引。
  - `SET-VECTOR-005-AC3` 编辑不回填 Key，留空保存保留原 Key，替换后后续请求使用新 Key；读取及操作响应无原始 Key。
  - `SET-VECTOR-005-AC4` 当前远程模型不可直接删除；切换后可以删除，其他配置和已有资料保留。
  - `SET-VECTOR-005-AC5` 官方上限只接受范围内整数，编辑回填已保存值，修改时实时显示自动预留和正文预算；无效值保留输入并报错，保存及测试使用同一预算。

#### SET-VECTOR-006 使用模型与索引失效

- 用户操作：在模型项点击「使用」，即时保存当前选择；不会启动资料向量化，退出重启也不自动建立或续建索引。索引更新运行期间不能切换或删除当前模型、编辑当前模型配置，须先取消更新。
- 系统行为：实际端点、模型名或输入预算变化后，已有不匹配索引立即失效；只改名称或 API Key 不使索引失效。保存新增配置及连接测试不自动选择模型。远程错误明确反馈，不使用其他模型兜底。
- 验收：
  - `SET-VECTOR-006-AC1` 当前标识和后续嵌入立即切换，选择跨重启保存；切换及启动均不产生资料嵌入请求。
  - `SET-VECTOR-006-AC2` 失效索引不能参与任何 KB 工具查询；在途旧模型结果不能写入新模型索引。
  - `SET-VECTOR-006-AC3` 端点或型号改变使相关索引失效；名称或 Key 修改不失效，新 Key 用于后续显式请求。
  - `SET-VECTOR-006-AC4` 输入上限改变使相关索引失效，重建使用新预算及身份，缓存和在途结果不跨预算复用。
  - `SET-VECTOR-006-AC5` 索引执行期间 UI 和 Main 均拒绝切换、删除当前模型或修改当前配置；取消或终态后解除。

#### SET-VECTOR-007 手动重建与恢复闭环

- 状态判断：以资料有效 generation 的模型身份判断失效，保留旧索引和正文。空知识库不显示模型变更失效提示；新增未索引资料仍遵循原有手动索引规则。
- 向量模型页：存在失效索引时在列表上方持续显示浅橙色提示「向量模型已变更，索引需要重新建立」，列出文件和网页待重建数量。「前往更新索引」跳转工作空间中有待重建资料的标签并定位索引操作，不自动执行任务。仅当原模型能完整复用全部有效索引时提供带模型名的快捷切回；部分重建后不能承诺切回恢复。不显示固定的切换后手动更新说明，不在向量页提供迁移进度、暂停、继续或重试。
- 工作空间页：文件和网页分别展示待重建标识和数量；模型不匹配的资料不能仍显示「已索引」，也不直接记为执行失败。已有「更新索引」在有失效资料时显示「重新建立索引」，保持可点击；缺失本地模型等实际阻断另显示原因。文件完成而网页尚有失效资料时，提示剩余网页并提供标签跳转。检查更新不启动嵌入，也不能把模型不匹配索引恢复为有效。
- 重建：仅用户点击后启动现有文件／网页索引任务；模型不匹配的资料即使内容未变也进入任务。按当前源资料和当前模型切分，复用有效基础解析缓存，不能层层沿用前一模型细分结果。来源不可用或调用失败按原任务规则反馈；已完成结果保留，未完成可手动重试。取消、失败和退出后保留失效状态，重启不自动续跑；离开页面不停止已启动任务。
- KB 行为：全局存在因模型切换而失效的有效资料时，搜索所有策略及资料列表统一返回明确错误，提示到设置的工作空间更新索引；不返回部分或关键词兜底结果。普通更新索引运行门禁保留。全部相关文件和网页完成、或切回完整匹配的原模型后恢复；普通文件阅读编辑和聊天不受该门禁限制。
- 验收：
  - `SET-VECTOR-007-AC1` 切换后旧索引逻辑失效，正文保留；未开始重建时切回完整匹配模型可恢复，部分重建不出现误导恢复入口。
  - `SET-VECTOR-007-AC2` 所有 KB 搜索策略和列表在失效时均失败，错误指明用户操作；无覆盖不足成功反馈。
  - `SET-VECTOR-007-AC3` 文件与网页任一仍失效或普通更新正在运行时 KB 不可用；全部完成后恢复，范围不扩大。
  - `SET-VECTOR-007-AC4` 两页提示、标签、数量和按钮随真实状态一致变化；跳转不执行索引；不出现固定说明或自动迁移操作。
  - `SET-VECTOR-007-AC5` 取消、失败、退出重启保留未完成项，重试只处理仍需处理的资料；不自动执行。
  - `SET-VECTOR-007-AC6` 新建及重建按当前模型预算完整切分并保存来源位置，成功后原子激活；失败和取消不激活部分结果。

### 4.7 使用帮助
