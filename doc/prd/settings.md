# Settings PRD

## 1. 文档定位

- 本文档是 `Settings -> 通用 / 大模型 / 工作空间（含网页资料） / 向量模型` 的产品规格来源，描述用户可见功能、操作逻辑、状态反馈、边界和验收标准。
- 设置页的用户可见行为、入口、反馈或结果发生变化时，必须同步更新本文。
- 后续实现、测试、评审和 AI 最终汇报都应引用本文中的需求编号与验收编号。

## 2. 产品目标

- 用户可以完成模型配置、工作空间与网页资料管理，以及向量模型下载。
- 关键入口、状态和操作结果在设置页内闭环，并稳定影响后续 workbench 和 AI 运行。

## 3. 范围

- 包含大模型可用服务配置的新增、编辑、删除和模型列表查看。
- 包含工作空间的添加、目录绑定、索引检查、索引更新、查看和移除。
- 包含工作区内网页资料的添加、检查更新、索引更新、打开和删除。
- 包含向量模型的列表加载、下载、进度展示和结果反馈。
- 包含设置页左侧栏中的官方使用帮助入口。
- 不包含 workbench 聊天、搜索和已修改文件回退逻辑。
- 不包含视觉风格与基础控件样式定义。

## 4. 术语

- 大模型配置：一条可供 workbench 使用的模型连接配置。
- 工作空间：一个具名资料容器，可绑定本地目录并挂载网页资料。
- 检查更新：读取当前真实数据，判断哪些文件或网页需要重新建立索引。
- 更新索引：只处理可索引或失败资料，把内容写入后续检索可用的本地索引。
- 网页资料：归属于某个工作区、由 URL 导入并抓取的外部网页内容。
- 向量模型：本地检索与知识库能力依赖的嵌入模型。

## 5. 需求规则

- 需求编号使用 `SET-<模块>-<三位序号>`。
- 验收编号使用 `SET-<模块>-<三位序号>-AC<序号>`。
- 需求编号稳定后不因措辞微调而重排；只有功能被废弃时才标记为废弃。

## 6. 需求明细

### 6.0 通用设置

#### SET-GENERAL-001 AI 运行系统通知

- 系统行为：通用设置默认开启 AI 运行终态通知。AI 运行成功、失败、取消以及应用启动时恢复为失败的中断任务，均发送一次电脑系统通知；等待审批和等待用户接管不发送通知。通知展示馆长 logo，内容只包含状态提示，不展示 AI 输出正文。
- 系统行为：点击系统通知后恢复应用窗口，并打开对应会话。关闭开关后不发送系统通知，但不影响 AI 运行和页面内状态。
- 验收：`SET-GENERAL-001-AC1` 默认开启；`SET-GENERAL-001-AC2` 四类终态各发送一次；`SET-GENERAL-001-AC3` 关闭后静默；`SET-GENERAL-001-AC4` 点击通知打开对应会话；`SET-GENERAL-001-AC5` 系统通知不可用时应用不崩溃；`SET-GENERAL-001-AC6` 通知展示馆长 logo。

#### SET-GENERAL-002 设置页窗口层与操作区

- 系统行为：Windows 设置页的原生窗口控制层独立位于业务内容上方；业务拖动区不遮挡侧栏、返回和页面操作按钮。非 Windows 平台保留页面顶部拖动区。
- 验收：
  - `SET-GENERAL-002-AC1` Windows 原生标题栏高度为 36px，业务内容从标题栏下方开始，页面按钮区不落入原生控制层。
  - `SET-GENERAL-002-AC2` 设置页主内容和侧栏拖动区可命中，侧栏折叠/展开按钮为 `no-drag` 且仍可操作。

### 6.1 大模型配置

#### SET-MODEL-001 页面加载与配置列表展示

- 系统行为：进入大模型页后自动拉取全部配置。该页面只管理可用服务，不维护默认、启用或当前状态。
- 验收：
  - `SET-MODEL-001-AC1` 页面打开后可见配置列表，而不是停留在未初始化状态。
  - `SET-MODEL-001-AC2` 配置列表展示用户填写的配置名称和模型服务地址。

#### SET-MODEL-002 新增、编辑配置与模型列表展示

- 系统行为：新增时打开空表单，编辑时打开预填表单。服务商适配类型默认隐藏并按服务地址推断；保存前校验表单。用户可以获取并查看远端模型列表。
- 验收：
  - `SET-MODEL-002-AC1` 新增时可填写配置名称、模型服务地址和 API Key，服务商适配类型默认不作为普通用户必填项展示。
  - `SET-MODEL-002-AC2` 编辑时会带出当前配置值，而不是空表单。
  - `SET-MODEL-002-AC3` 必填字段不完整时，保存不会提交。
  - `SET-MODEL-002-AC4` 获取模型列表成功后，配置列表会展示可用模型数量，点击后可在弹窗中查看具体模型。
  - `SET-MODEL-002-AC5` 获取模型列表失败时，配置列表和模型列表弹窗都会给出明确错误提示。
  - `SET-MODEL-002-AC6` 新增、编辑和模型列表弹窗点击遮罩区域时保持打开，避免用户误触丢失输入或列表状态；用户仍可通过取消、关闭或完成操作退出。

#### SET-MODEL-003 删除配置

- 系统行为：删除配置后刷新列表并移除对应记录。
- 验收：
  - `SET-MODEL-003-AC1` 删除成功后，该配置不再出现在列表中。
  - `SET-MODEL-003-AC2` 删除失败时，界面会给出明确错误提示。

#### SET-MODEL-004 免费 AI Key 入口

- 系统行为：大模型配置页在配置数量与“新增配置”之间展示“免费获取 AI Key”入口，点击后通过系统默认浏览器打开官网免费 Key 页面 `https://www.ncurator.com/zh/free-keys`，当前设置页保持不变。
- 验收：
  - `SET-MODEL-004-AC1` 入口位于配置数量与“新增配置”之间，并与操作区保持对齐。
  - `SET-MODEL-004-AC2` 点击入口后调用系统外链能力打开官网免费 Key 页面，不改变当前设置页路由。

### 6.2 工作空间容器

工作空间是独立于本地目录的具名资料容器。每个工作空间都包含两个固定子区域：

- 文件视图：允许单独设置当前工作空间的本地目录，并查看真实目录结构、索引状态、索引错误和更新操作。
- 网页资料视图：用于查看和管理当前工作空间下的网页资料，作为与文件平级的资料类型存在。

#### SET-WORKSPACE-001 页面加载与默认选中

- 系统行为：进入工作空间页后自动拉取工作空间列表，并默认选中第一条；详情区展示当前工作空间公共信息与 `文件 / 网页` 两个 tab。
- 验收：
  - `SET-WORKSPACE-001-AC1` 页面打开后，列表和详情区会完成初始化，而不是依赖手动刷新。
  - `SET-WORKSPACE-001-AC2` 有工作空间时，详情区默认显示第一条工作空间名称、文件/网页 tab 和对应内容。

#### SET-WORKSPACE-002 添加工作空间

- 系统行为：点击添加工作空间后弹出名称输入弹窗；输入名称成功后立即创建空工作空间，并自动切到新项。
- 验收：
  - `SET-WORKSPACE-002-AC1` 工作空间名称为空时，不允许提交创建。
  - `SET-WORKSPACE-002-AC2` 创建成功后，新工作空间立刻出现在列表中并成为当前选中项。
  - `SET-WORKSPACE-002-AC3` 创建工作空间弹窗点击遮罩区域时保持打开，用户输入不会因误触被清空。

#### SET-WORKSPACE-006 设置文件目录与移除工作空间

- 系统行为：文件 tab 支持为当前工作空间设置或替换本地目录；未设置时提示用户设置后才能在 Workbench 发送任务。用户也可以移除工作空间；移除后，该工作空间不再出现在资料范围和聊天范围中。
- 设置目录成功后立即保存目录绑定并开始后台文件扫描；目录树可先读取根目录首层，扫描进度独立显示，不阻塞目录浏览。
- 验收：
  - `SET-WORKSPACE-006-AC1` 点击“设置工作文件地址”后，可为当前工作空间绑定或替换本地目录。
  - `SET-WORKSPACE-006-AC2` 移除成功后，该工作空间从列表中消失，且其本地资料与网页资料都不会继续出现在后续资料范围选择里。
  - `SET-WORKSPACE-006-AC3` 当前工作空间未设置文件目录时，文件 tab 会展示轻提示，明确说明设置后才能在 Workbench 中发送任务。
  - `SET-WORKSPACE-006-AC4` 设置或替换目录后，页面可见“正在扫描工作目录”的活动进度；用户无需等待扫描完成即可看到根目录首层。

#### SET-WORKSPACE-007 空态与无文件提示

- 系统行为：无工作空间时展示空态；当前目录没有可显示文件时展示空态。
- 验收：
  - `SET-WORKSPACE-007-AC1` 没有工作空间时，详情区不是空白页，而是明确提示用户先选择或添加。
  - `SET-WORKSPACE-007-AC2` 当前目录没有可显示文件时，目录树区域显示明确空态。

### 6.3 当前工作空间下的本地文件视图

- `SET-WORKSPACE-003-AC5` 检查运行期间目录树不在 loading 与空态之间切换；任务终态刷新后保留当前目录展开状态。
- `SET-WORKSPACE-004-AC6` 更新索引执行期间目录读取次数为零，任务终态仅刷新一次；目录树不得因每个文件完成而闪烁或折叠。

目录树刷新契约：进入或选中工作空间时读取一次当前根目录；检查运行期间不重载目录树、不清空已显示节点；任务进入成功或失败终态后，仅对当前选中工作空间执行一次目录树刷新。扫描总数未知时显示活动状态，不显示静态 0% 进度。

更新索引逐文件处理期间只更新索引 job 进度，不广播目录刷新；job 终态统一触发一次当前目录树和摘要更新，刷新过程中保留旧节点与展开状态，返回后替换可见数据。刷新请求发生竞态时只接受最新响应，旧响应不得覆盖当前目录或 loading 状态。

#### SET-WORKSPACE-003 检查目录变化

- 系统行为：点击“检查更新”后启动持久化后台任务，读取真实目录并识别新增、变更、删除和未索引文件。执行中两个操作按钮都不可重复触发，页面展示总进度；完成后同步刷新索引摘要和目录树状态。
- 验收：
  - `SET-WORKSPACE-003-AC1` 检查执行中，界面可见持久化进度信息，且“检查更新”和“更新索引”按钮同时禁用。
  - `SET-WORKSPACE-003-AC2` 检查成功后，最近检查时间、状态和目录树同步刷新。
  - `SET-WORKSPACE-003-AC3` 检查执行中离开工作空间页再进入时，仍能恢复当前检查进度。
  - `SET-WORKSPACE-003-AC4` 程序关闭导致检查中断时，下次启动后该任务收敛为失败并退出执行中状态。

#### SET-WORKSPACE-004 更新文件索引

- 系统行为：点击“更新索引”后启动持久化后台任务，先检查目录变化，再处理新增、变更、可索引和失败文件。执行中两个操作按钮都不可重复触发，页面按目标文件总数展示进度。界面只提供“检查更新”和“更新索引”。
- 验收：
  - `SET-WORKSPACE-004-AC1` 更新索引时，实际处理范围会包含新增、变更、未索引和失败文件，而不是只停留在界面展示。
  - `SET-WORKSPACE-004-AC2` 更新成功后，可索引摘要和文件节点状态同步刷新；失败文件继续参与下次更新索引。
  - `SET-WORKSPACE-004-AC3` 更新索引执行中，界面可见持久化总进度，且“检查更新”和“更新索引”按钮同时禁用。
  - `SET-WORKSPACE-004-AC4` 更新索引执行中离开工作空间页再进入时，仍能恢复当前索引进度。
  - `SET-WORKSPACE-004-AC5` 程序关闭导致索引中断时，下次启动后任务和索引中的文件都收敛为失败状态。

#### SET-WORKSPACE-005 工作空间详情总览与子区域承载

- 系统行为：详情区展示工作空间名称；文件与网页资料通过同级 tab 切换，各自展示索引状态。
- 验收：
  - `SET-WORKSPACE-005-AC1` 工作空间头部只展示名称和工作空间操作，不展示跨资料类型的全局索引状态。
  - `SET-WORKSPACE-005-AC2` 文件 tab 中始终能查看可索引数；可索引数包含失败文件，存在失败文件时在可索引块内以辅助文案提示失败数量。
  - `SET-WORKSPACE-005-AC3` 选中工作区后，详情区使用 `文件 / 网页` tab 直接切换当前工作区下的两类资料管理区域，而不是跳到独立页面。
  - `SET-WORKSPACE-005-AC4` 左侧工作空间列表项能同时表达文件数量和网页数量，而不是只表达文件视角。

#### SET-WORKSPACE-008 目录树显示真实目录与索引状态

- 系统行为：目录树显示当前真实目录，不依赖历史快照。进入文件 tab 时只读取当前工作空间根目录的第一层；用户展开目录时才读取该目录的第一层，已读取目录在当前页面缓存。目录结构始终来自本机文件系统，索引库仅补充当前可见文件的状态。当前支持索引 `.doc`、`.docx`、`.pdf`、`.md`、`.markdown`、`.txt`；文件项只展示文件名和状态 tag。
- 可见性规则：任意层级中名称以 `.` 开头的文件或目录均不展示；除此之外不维护额外目录黑名单，`node_modules` 等目录正常可见，但不会因进入页面或切换工作空间而被递归读取。
- 验收：
  - `SET-WORKSPACE-008-AC1` 用户能在目录树中看到当前真实目录结构，而不是过期快照。
  - `SET-WORKSPACE-008-AC2` 支持索引的文件节点会展示索引状态，不支持索引的文件不会伪装成可索引文件。
  - `SET-WORKSPACE-008-AC3` 文件视图内可直接设置当前工作空间的工作文件地址。
  - `SET-WORKSPACE-008-AC4` 根目录首次读取显示加载反馈；展开子目录时仅该目录显示加载反馈，读取失败可重试，且不会显示为“空目录”。
  - `SET-WORKSPACE-008-AC5` 目录树不提供全部展开或全部折叠；根目录首层之外仅由用户逐目录展开。

### 6.4 当前工作空间下的网页资料视图

#### SET-WEB-001 页面加载与统一布局

- 系统行为：进入工作空间页并选中某个工作区后，详情区自动拉取该工作区下的网页资料列表；网页 tab 使用与文件 tab 同构的双栏布局：左侧索引状态和操作，右侧网页列表。
- 验收：
  - `SET-WEB-001-AC1` 选中工作区后，当前工作区的网页资料列表和索引摘要完成初始化。
  - `SET-WEB-001-AC2` 网页 tab 左侧始终显示可索引数和核心操作按钮；可索引数包含失败网页，存在失败网页时在可索引块内以辅助文案提示失败数量。
  - `SET-WEB-001-AC3` 网页 tab 右侧始终显示网页列表，而不是单条详情页。

#### SET-WEB-002 添加网页资料

- 系统行为：添加弹窗支持一次输入多行 URL，每行一条。提交成功后加入当前工作区抓取队列，关闭弹窗并刷新列表。
- 验收：
  - `SET-WEB-002-AC1` 输入为空时，提交会被拦截，并提示至少输入一个 URL。
  - `SET-WEB-002-AC2` 提交成功后，提示“网页资料已加入队列”，输入内容被清空。
  - `SET-WEB-002-AC3` 提交成功后，添加弹窗关闭，且当前工作区的网页资料列表完成刷新。
  - `SET-WEB-002-AC4` 添加网页资料弹窗点击遮罩区域时保持打开，已输入 URL 不会因误触丢失。

#### SET-WEB-003 检查网页更新

- 系统行为：点击“检查更新”后启动持久化后台任务，只检查当前工作区网页是否变化。执行中两个操作按钮都不可重复触发；变化网页标记为 `可索引`，不直接重建索引。
- 验收：
  - `SET-WEB-003-AC1` 检查执行中，界面可见持久化进度信息，且“检查更新”和“更新索引”按钮同时禁用。
  - `SET-WEB-003-AC2` 检查成功后，网页列表的状态会刷新。
  - `SET-WEB-003-AC3` 检查执行中离开网页 tab 再进入时，仍能恢复当前检查进度。
  - `SET-WEB-003-AC4` 程序关闭导致检查中断时，下次启动后该任务收敛为失败并退出执行中状态。

#### SET-WEB-004 更新网页索引

- 系统行为：点击“更新索引”时启动持久化后台任务，仅对当前工作区下状态为 `可索引 / 爬取失败 / 索引失败` 的网页执行爬取和索引更新；有抓取动作时先展示“步骤 1/2 抓取网页”，再展示“步骤 2/2 建立索引”，无抓取动作时直接展示第二步。
- 验收：
  - `SET-WEB-004-AC1` 更新索引执行中，网页状态会进入 `爬取中` 或 `索引中`。
  - `SET-WEB-004-AC2` 更新成功后，网页状态变为 `已索引`，抓取时间同步刷新。
  - `SET-WEB-004-AC3` 更新失败时，会区分 `爬取失败` 与 `索引失败`。
  - `SET-WEB-004-AC4` 更新索引执行中，界面可见抓取/索引分阶段进度，且“检查更新”和“更新索引”按钮同时禁用。
  - `SET-WEB-004-AC5` 更新索引执行中离开网页 tab 再进入时，仍能恢复当前阶段和进度。
  - `SET-WEB-004-AC6` 程序关闭导致网页索引中断时，下次启动后任务收敛为失败，`爬取中` 网页变为 `爬取失败`，`索引中` 网页变为 `索引失败`。

#### SET-WEB-005 列表项信息、外链打开与删除

- 系统行为：网页列表项展示标题、URL、状态和抓取时间；点击“打开”用系统浏览器打开；删除后刷新当前工作区列表。
- 验收：
  - `SET-WEB-005-AC1` 列表项展示标题、URL、状态和抓取时间。
  - `SET-WEB-005-AC2` 点击“打开”后，用系统浏览器打开原网页，而不是进入本地文档预览。
  - `SET-WEB-005-AC3` 删除成功后，该网页资料从列表中消失。

### 6.5 向量模型下载

#### SET-VECTOR-001 模型列表加载

- 系统行为：进入向量模型页后自动拉取模型列表，并展示名称、说明、标签和是否已安装。
- 验收：
  - `SET-VECTOR-001-AC1` 模型列表加载成功后，可区分已安装模型与可下载模型。
  - `SET-VECTOR-001-AC2` 获取模型列表失败时，页面给出明确错误提示。

#### SET-VECTOR-002 单任务下载与进度显示

- 系统行为：同一时间只允许一个下载任务进行；下载过程中展示百分比、当前文件和文件完成数。
- 验收：
  - `SET-VECTOR-002-AC1` 已有下载任务时，其他模型的下载入口不可继续触发新任务。
  - `SET-VECTOR-002-AC2` 下载过程中，界面持续更新当前文件、完成数和总进度。
  - `SET-VECTOR-002-AC3` 离开向量模型页面不会中断下载；再次进入页面时恢复当前文件、完成数和总进度。
  - `SET-VECTOR-002-AC4` 应用启动时若存在进行中的下载快照，后台自动恢复任务，页面展示恢复后的进度。

#### SET-VECTOR-003 下载完成与错误收敛

- 系统行为：下载完成后自动刷新列表并切换到已安装状态；下载失败时记录错误并给出反馈。
- 验收：
  - `SET-VECTOR-003-AC1` 下载完成后，对应模型显示为“已安装”，不再显示下载按钮。
  - `SET-VECTOR-003-AC2` 下载失败时，界面提示失败原因，并退出下载中状态。

#### SET-VECTOR-004 已安装模型删除确认与反馈

- 系统行为：已安装模型点击“删除”后先显示确认提示；确认后执行删除，取消时保持已安装状态。
- 验收：
  - `SET-VECTOR-004-AC1` 用户确认删除且删除成功后，模型回到可下载状态。
  - `SET-VECTOR-004-AC2` 删除失败时页面提示失败原因，并保持已安装状态。
  - `SET-VECTOR-004-AC3` 点击删除入口后先出现确认弹框，不立即执行删除。
  - `SET-VECTOR-004-AC4` 取消确认后不执行删除，也不进入成功或失败结果态。

### 6.6 使用帮助

#### SET-HELP-001 设置页使用帮助入口

- 系统行为：设置页左侧栏在“向量模型”下方展示同级、同样式的“使用帮助”入口，点击后通过系统默认浏览器打开官方中文使用手册 `https://www.ncurator.com/zh/manual`，当前设置页保持不变。
- 验收：
  - `SET-HELP-001-AC1` “使用帮助”入口紧接在“向量模型”下方，使用与其他设置菜单项一致的样式，并具有“查看使用帮助”的可访问名称。
  - `SET-HELP-001-AC2` 点击“使用帮助”后调用系统外链能力打开官方中文使用手册，不改变当前设置页路由。
