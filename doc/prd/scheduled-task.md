# Scheduled Task PRD（定时任务）

## 1. 文档定位

- 本文是「定时任务」功能的用户可见行为规格来源，描述入口、面板交互、配置字段、调度执行与边界。
- 定时任务的用户可见行为、入口、反馈或调度规则发生变化时，必须同步更新本文。
- 后续实现、测试、评审和 AI 最终汇报都应引用本文中的需求编号与验收编号。

## 2. 产品目标

- 用户可配置一个或多个定时任务，在程序运行期间按每天 / 每周的指定时间点，自动在对应工作空间下创建新会话并发送任务提示词。
- 定时任务自动执行时不操作用户当前页面，但对应会话列表需要刷新，让用户能看到新会话及其运行状态。

## 3. 范围

- 包含左侧栏「定时任务」入口与独立右侧面板。
- 包含定时任务的列表展示、新增、编辑、删除和启用开关。
- 包含调度时间（每天 / 每周 + 具体时间点）、名称、工作空间、任务提示词、主模型、视觉模型、AI 推进偏好和执行权限的配置。
- 包含到点后在对应工作空间下创建新会话、发送任务消息并刷新会话列表。
- 不包含设置页中的大模型配置、工作空间与网页资料管理逻辑（复用现有能力）。
- 不包含视觉风格与基础控件样式定义。

## 4. 术语

- 定时任务：一条持久化的调度配置，包含触发时间与一次 AI 任务的完整参数。
- 调度时间：每天一个时间点，或每周某个星期几 + 一个时间点。
- 任务提示词：到点发送给 AI 的用户消息正文，用于描述想让 AI 完成的事。
- 执行权限：与 workbench 一致，`审核` / `完全访问`；定时任务默认 `完全访问`。

## 5. 需求规则

- 需求编号使用 `ST-<模块>-<三位序号>`。
- 验收编号使用 `ST-<模块>-<三位序号>-AC<序号>`。

## 6. 需求明细

### 6.1 入口与视图

#### ST-ENTRY-001 左侧栏入口

- 系统行为：Workbench 左侧栏「新对话」下方展示同级、同样式的「定时任务」入口；点击后整个主区域（除左侧会话列表外）切换为定时任务视图，不展示聊天对话和资源面板。
- 验收：
  - `ST-ENTRY-001-AC1` 「定时任务」入口位于「新对话」下方，使用与「新对话」一致的侧栏选项样式。
  - `ST-ENTRY-001-AC2` 点击入口后，主区域整块切换为定时任务视图，聊天对话与资源面板不再显示。

#### ST-VIEW-001 视图独立与返回

- 系统行为：定时任务视图是独立自包含组件，占据除左侧会话列表外的整个主区域；该视图没有聊天对话。视图顶部提供标题与关闭入口，点击关闭或点击「新对话」后返回聊天视图。打开搜索 / 文件预览 / 浏览器等资源动作同样返回聊天视图。
- 验收：
  - `ST-VIEW-001-AC1` 定时任务视图中不展示聊天对话或资源面板。
  - `ST-VIEW-001-AC2` 视图顶部标题栏提供关闭入口，点击后收起定时任务视图并返回聊天。
  - `ST-VIEW-001-AC3` 点击「新对话」或打开搜索 / 文件预览 / 浏览器等资源动作后，定时任务视图关闭。

### 6.2 列表与配置

#### ST-LIST-001 列表展示

- 系统行为：面板打开后拉取全部定时任务并展示；每个任务项展示名称、调度时间摘要、主模型名称和启用开关。无任务时展示空态与「新增配置」入口。
- 验收：
  - `ST-LIST-001-AC1` 面板打开后可见已配置任务列表，而不是未初始化状态。
  - `ST-LIST-001-AC2` 任务项展示名称、调度时间摘要和主模型名称。
  - `ST-LIST-001-AC3` 无任务时展示空态和「新增配置」入口。

#### ST-FORM-001 新增与编辑配置

- 系统行为：新增打开空表单，编辑打开预填表单。字段包括名称、任务提示词、执行时间（每天 / 每周 + 星期 + 时间点）、工作空间、主模型、视觉模型（可选，不选跟随主模型）、AI 推进偏好和执行权限。保存前校验必填项；模型选择复用现有大模型配置与远端模型列表。
- 验收：
  - `ST-FORM-001-AC1` 新增时可填写全部字段并保存，编辑时带出当前配置值。
  - `ST-FORM-001-AC2` 名称、任务提示词、执行时间、工作空间或主模型缺失时，保存被拦截并给出明确提示。
  - `ST-FORM-001-AC3` 选择「每周」时必须选择星期几；选择「审核」时展示无人值守可能阻塞的提示。
  - `ST-FORM-001-AC4` 新增表单点击遮罩不关闭，避免误触丢失输入。

#### ST-SWITCH-001 启用开关

- 系统行为：每个任务项提供启用开关，默认关闭；只有开启后该定时任务才会在到点执行。切换后立即生效。
- 验收：
  - `ST-SWITCH-001-AC1` 新建任务默认关闭，需用户主动开启才会执行。
  - `ST-SWITCH-001-AC2` 关闭后该任务到点不再触发。

#### ST-DELETE-001 删除

- 系统行为：删除前二次确认，确认后从列表移除。
- 验收：
  - `ST-DELETE-001-AC1` 删除前有确认弹窗，取消不删除。
  - `ST-DELETE-001-AC2` 确认后任务从列表移除。

### 6.3 调度执行

#### ST-RUN-001 到点触发

- 系统行为：程序运行期间，已启用任务到达调度时间时，在其配置的工作空间下创建新会话并发送任务提示词，使用配置的主模型、视觉模型、偏好和执行权限；不操作用户当前页面。工作空间不可用（未绑定目录）或模型失效时跳过本次并推进到下一调度时间。
- 验收：
  - `ST-RUN-001-AC1` 到点后在工作空间下创建新会话并发送任务消息，新会话标题取任务提示词前 20 个字符。
  - `ST-RUN-001-AC2` 触发过程不改变用户当前正在查看的会话或输入草稿。
  - `ST-RUN-001-AC3` 工作空间未绑定目录时跳过本次执行，不产生空会话。

#### ST-RUN-002 会话列表刷新

- 系统行为：定时任务触发并创建新会话后，广播会话列表刷新，Workbench 会话列表展示新会话及其运行状态。
- 验收：
  - `ST-RUN-002-AC1` 定时任务触发后，会话列表出现新会话并显示运行状态。
  - `ST-RUN-002-AC2` 用户无需手动刷新即可看到新会话。

#### ST-RUN-003 程序关闭错过不补跑

- 系统行为：程序关闭期间错过的调度时间不补跑，重新打开后只等待下一次到点。
- 验收：
  - `ST-RUN-003-AC1` 程序关闭期间错过的调度时间，重新打开后不会立即触发补跑。

## 7. 非目标

- 不定义大模型配置、工作空间与网页资料的管理逻辑。
- 不定义 workbench 聊天、搜索、资料范围与已修改文件回退逻辑。
- 不定义页面视觉风格、配色 token 或圆角规则。
