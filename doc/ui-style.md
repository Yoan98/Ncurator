# UI 整体风格

## 0. 文档边界

- 本文档只定义视觉系统与通用交互 affordance。
- 用户可见功能、操作逻辑、状态反馈和验收标准统一放在 `doc/prd/**`。
- 新增或修改业务功能时，不要把流程规则、业务状态和功能验收写回本文。

## 1. 设计语言

- 全前端统一使用 **ink-mono 墨白主题**：黑白灰为主，少量朱砂只服务于危险、拒绝、错误或待确认。
- 整体气质是克制、安静、偏编辑器与资料工作台，而不是宣传页或强装饰界面。
- 水墨感来自留白、淡墨洗底、细线、层级和节奏，不使用大面积彩色渐变或高饱和状态色。
- 优先用版式、字重、边界、图标和微弱明暗变化表达层级；避免堆叠卡片和厚重阴影。

## 2. 配色

### Token

- `canvas`：`#F6F5F1`
- `paper`：`#FFFDF8`
- `paper-soft`：`#FAF9F5`
- `wash`：`#F0EFEB`
- `wash-strong`：`#E8E6DF`
- `ink`：`#181818`
- `ink-2`：`#3F3F3D`
- `ink-3`：`#6E6D69`
- `ink-4`：`#9C9A94`
- `line`：`#E1DED6`
- `line-strong`：`#CBC7BD`
- `seal`：`#A83A31`

### 使用规则

- 背景默认使用 `canvas`，主工作面使用 `paper`，弱区域使用 `paper-soft` 或 `wash`。
- 主按钮、主链接、焦点态使用 `ink`，hover 使用 `ink-2` 或 `wash`。
- 常规状态统一使用灰阶、图标与文字区分；不要用蓝、绿、黄、紫等彩色状态体系。
- 危险、拒绝、错误、关键确认才使用小面积 `seal`，并配合浅朱砂底或边线。
- 禁止恢复旧 Claude/陶土色体系，包括 `#D97757`、`#C66A4A`、`#FBF5F2`、`#F4E5DF`、`#F5F5F4`。

## 3. 尺度系统

### 圆角

- 控件：`10px`
- 内嵌块：`12px-14px`
- 主面板：`18px-24px`
- pill / tag：`999px`

### 字级

- 元信息：`12px`
- 正文：`14px`
- 区块标题：`15px-16px`
- 页面标题：`18px`
- 避免散落使用过多相近字号。

### 间距

- 紧凑控件内边距优先使用 `10 / 12 / 14`
- 面板间距优先使用 `16 / 20 / 24`
- 页面级容器优先使用 `20 / 24`

### 阴影

- 默认只用轻阴影：`0 1px 2px rgba(24, 24, 24, 0.04)`。
- 浮层可用更明显但柔和的黑墨阴影。
- 禁止为了“高级感”添加厚重彩色阴影。

## 4. Surface 层级

- `canvas`：页面底色，只承载布局。
- `paper`：主工作面板，细边框、轻阴影。
- `paper-soft`：需要区分但不抢主层级的柔和区域。
- `wash`：面板内部的次层区域，用于摘要、状态块、导航块、用户消息气泡。
- `seal`：危险或确认提示，不作为普通品牌底色。

## 5. 组件规则

### Button

- 主按钮只给主动作，黑底白字。
- 次按钮保持细边框、浅背景或透明底。
- 图标按钮与常规按钮共享圆角、hover、focus 规则。
- 不使用高饱和色表达普通 hover 或选中。

### Input / Select / Composer

- 桌面工作台保持紧凑高度，不做宣传页式大输入框。
- focus 使用 `ink` 边框与 `wash-strong` ring。
- 一个区域只保留一个主输入焦点。
- Workbench 审核态与补工作区态占用 composer slot，互斥隐藏输入框。

### Tag / Status

- 状态默认使用图标 + label + 灰阶 tag。
- tag 用于扫描，不用于长句说明。
- 相邻 tag 的视觉重量要低于正文标题。
- 只有失败、拒绝、危险态允许使用 `seal`。

### Icon

- 默认使用线性图标。
- 小图标 `16px`，常规图标 `18px-20px`。
- 图标优先承担扫描职责：来源、状态、动作、风险、模式。

## 6. 文字与文案

- 页面不是说明书，不要把状态说明写成长段解释。
- 能放进 tooltip、tag、状态条的文案，不要放成段落。
- 标题只负责定位，辅助文案只负责补充范围或行为。

## 7. 动效与交互

- 默认过渡时长 `180-200ms`。
- hover 只做轻微位移、边框变色、背景变浅，不做夸张动画。
- 同类元素必须共享同一套 hover / active / focus 反馈。

## 8. Cursor 规则

- 可点击元素统一使用 `pointer`。
- 文本输入、`textarea`、`contenteditable` 使用 `text`。
- 帮助提示使用 `help`。
- 禁用态统一使用 `not-allowed`。

## 9. 辅助功能

- 所有交互元素必须可键盘访问。
- focus ring 必须清晰可见。
- 文本和背景对比度需满足正常阅读。
