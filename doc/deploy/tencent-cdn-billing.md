# 腾讯云国内下载通道：资费与采购定稿

定稿日期：2026-09（与 COS/CDN 接入同期）。

## 1. 结论先看

- **不要先买大流量套餐**。默认按量后付费（小时结）；有下载才扣费。
- **先做防爆账单，再谈优惠包**：用量封顶 + 余额告警；可选领取企业新用户试用流量包。
- **钱主要花在 CDN 下行**；COS 回源只在节点冷启动时产生；不要买 COS 外网下行包。
- 账号：热纳科技主账号；可用余额建议保持正数；余额低于 **50 元**告警。

## 2. 链路与计费关系（为什么这样买）

```text
发版脚本（密钥写 COS）
        → COS 私有桶 ncurator-1324873382（广州）
        → 腾讯云 CDN（中国境内 / 下载大文件）
        → https://download.guanzhangai.cn
```

| 计费项       | 何时产生                | 是否应用流量包抵扣                    | 定稿态度                     |
| ------------ | ----------------------- | ------------------------------------- | ---------------------------- |
| CDN 下行     | 用户从 CDN 节点下载     | 是（境内 CDN 流量包 / 试用包）        | 大头；按需后付或以后买包     |
| COS CDN 回源 | 节点缓存未命中时桶→节点 | 否（另计，可用 COS 回源包但不必先买） | 靠长缓存压低；不囤包         |
| COS 外网下行 | 直打 `*.myqcloud.com`   | COS 外网下行包                        | **不走这条，不要买**         |
| COS 存储     | 桶内对象占用            | 存储包                                | 安装包体量小，后付即可       |
| HTTPS 请求   | HTTPS 访问次数          | 每月前 300 万次免费                   | 更新检查通常够用，不买请求包 |
| QUIC         | 开启 QUIC 后按请求      | —                                     | **不要开**                   |

对象布局（与资费相关）：每平台只保留最新 `artifacts/...` 大文件；CDN 节点缓存遵循源站 `Cache-Control`（安装包一年 `immutable`，`fragment.json` 与 `updates/latest`、`releases/latest` 指针 `no-store`）。官网与自动更新共用同一 artifacts URL，减少回源。

## 3. 已落地的防刷 / 控费配置

| 项            | 定稿值                                                         | 说明                                                                             |
| ------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| IP 限频       | 默认约 100 QPS                                                 | 挡不住分布式刷流量                                                               |
| 用量封顶      | 已开启                                                         | 超限约 10 分钟后整站 404 / 关 CDN，**不自动解封**；延迟窗口内流量仍计费          |
| 累计封顶      | **当天 100GB**，80% 告警                                       | 自然日清零                                                                       |
| 瞬间封顶      | **每 5 分钟 10GB**                                             | 防短时猛刷                                                                       |
| 余额预警      | **低于 50 元**                                                 | 费用中心订阅；连续提醒最多约 5 天                                                |
| 自动充值      | **不开**                                                       | 避免异常划卡                                                                     |
| COS 默认域名  | 标「高风险」可忽略                                             | 不对用户暴露；对外只用自定义 CDN 域名                                            |
| HTTP 头部缓存 | 已开启                                                         | 透传源站 `Cache-Control` 等头部                                                  |
| 节点缓存      | 全部文件遵循源站；`/updates/latest`、`/releases/latest` 不缓存 | 安装包按源站一年 `immutable` 缓存；指针 `no-store`。浏览器缓存不另配，跟随源站头 |

粗算：100GB/日封顶量级约对应「最多几十元级 CDN 日费」的上限（刊例约 0.21 元/GB），不是无限账单。

## 4. 刊例价参考（中国境内，以后付为准）

以腾讯云文档当时公示为准，实际以控制台/账单为准。

### 4.1 CDN 下行后付费（月度阶梯，约）

| 阶梯     | 约（元/GB） |
| -------- | ----------- |
| 0–2 TB   | **0.21**    |
| 2–10 TB  | 0.20        |
| 10–50 TB | 0.18        |
| …        | 更低        |

HTTPS：账号每月约 **300 万次**免费，超出约 0.05 元/万次。

### 4.2 预付费境内 CDN 流量包（刊例，1 个月有效）

| 规格  | 约价   | 折合        |
| ----- | ------ | ----------- |
| 100GB | 16 元  | ~0.16 元/GB |
| 500GB | 80 元  | ~0.16 元/GB |
| 1TB   | 156 元 | ~0.15 元/GB |

12 个月规格是「同一份流量、更长有效期」，不是每月刷新。包用完自动转后付费。**买包不能代替用量封顶。**

### 4.3 试用包

- 企业新用户：常有 **0 元 500GB** 境内 CDN 试用（有效期约 1 个月，以活动页为准）。
- 领取入口示例：https://cloud.tencent.com/act/pro/video_freetrial 、https://cloud.tencent.com/product/cdn
- 用主账号领取；临近有真实下载时再领更划算；不要勾无意义的加购/自动续订。

### 4.4 COS 侧（作 CDN 源时）

- 标准存储容量：约 0.12 元/GB/月量级（广州），几个安装包通常可忽略。
- CDN 回源：约 0.15 元/GB 量级；缓存命中后很少产生。
- **不要买**：COS 外网下行包、仅为下载站囤的存储包、全球加速。

## 5. 用量直觉（体积按最近实测快照）

基准（十进制 GB，后付费刊例；安装包体积随版本变化，数字为量级参考）：

| 包                                                 | 约体积              | CDN 下行（0.21 元/GB） | 冷回源一次（0.15 元/GB） |
| -------------------------------------------------- | ------------------- | ---------------------- | ------------------------ |
| Windows `馆长-1.0.1-Windows-x64.exe`（1.0.1 实测） | ~0.309 GB（309 MB） | ~0.065 元              | ~0.046 元                |
| macOS `馆长-1.0.4-macos-arm64.dmg`（1.0.4 实测）   | ~0.274 GB（274 MB） | ~0.058 元              | ~0.041 元                |

单人成本怎么读：

| 场景                               | 约费用                                                    |
| ---------------------------------- | --------------------------------------------------------- |
| 1 人完整下载（节点已有缓存，常见） | 约 **0.06 元**（几乎只有 CDN 下行）                       |
| 1 人完整下载且打到冷节点（少见）   | 约 **0.10 元**（CDN 下行 + 该节点回源一次）               |
| 1000 次完整下载（多数命中缓存）    | 约 **55–65 元** CDN；回源按节点摊薄，通常远小于下行       |
| 500GB CDN 试用包                   | 大约 **1600 次** Windows 完整下载，或 **1800 次** Mac DMG |

回源：同一版本大文件在每个热节点大约回源一次，之后同节点主要只付 CDN 下行。自动更新若只拉 Mac zip（1.0.4 实测约 0.289 GB），量级与上表接近。

## 6. 采购决策清单（以后照这个做）

**日常低用量阶段**

1. 保持账号有正余额（约 100–200 元即可）。
2. 保持 50 元余额预警。
3. 保持用量封顶（日 100GB + 5 分钟 10GB）；阈值要改再动控制台。
4. 可选：领 500GB 试用包。
5. **不买**付费大流量包、HTTPS 包、QUIC、COS 外网下行包。

**用量稳定后**

- 若月 CDN 下行长期明显高于几百 GB，再对比后付费与流量包（约 0.16 vs 0.21 元/GB）决定是否买境内包。
- 证书（如 `download.guanzhangai.cn` DV）到期前检查续期即可。

**控制台入口备忘**

- 费用中心 / 充值：https://console.cloud.tencent.com/expense
- CDN 域名 / 封顶 / HTTPS：域名管理 → `download.guanzhangai.cn`
- 资源包：https://console.cloud.tencent.com/cdn/package
- 流量包购买：https://buy.cloud.tencent.com/cdn
