# NCurator Logo Assets

This folder is the portable logo asset package for NCurator.

## Primary Files

- `ncurator-logo.svg`: master editable logo.
- `ncurator-logo-small.svg`: simplified logo for very small sizes.
- `ncurator-logo-1024.png`: main app icon source.
- `ncurator-logo.icns`: macOS app icon.
- `ncurator-logo.ico`: Windows app icon.

## PNG Sizes

The `png/` folder contains:

- `ncurator-logo-1024.png`
- `ncurator-logo-512.png`
- `ncurator-logo-256.png`
- `ncurator-logo-128.png`
- `ncurator-logo-64.png`
- `ncurator-logo-48.png`
- `ncurator-logo-32.png`
- `ncurator-logo-24.png`
- `ncurator-logo-16.png`

The 16-64px files use the simplified small-size SVG.

## Design Note

The dark circle is the stable base. The brim and thought dots slightly break out of the circle to express a warm, reliable work partner that can "think it through" for users.
