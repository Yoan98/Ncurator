## Requirements
### Requirement: 网页类型文档进入统一索引管线
系统 MUST 将网页类型导入的内容进入与文件一致的分段、嵌入与全文索引管线，使网页内容可参与向量检索与全文检索。

#### Scenario: 网页内容可被索引
- **WHEN** 一个网页 URL 导入成功并产生正文文本
- **THEN** 系统 MUST 对正文文本进行分段与索引，使其在向量检索与全文检索中可被召回

### Requirement: 混合搜索可召回网页类型结果
系统 MUST 在混合搜索结果中包含网页类型文档，并以与文件一致的排序融合策略处理网页结果与文件结果。

#### Scenario: 搜索召回网页结果
- **WHEN** 用户搜索的关键词仅存在于某个已导入的网页正文中
- **THEN** 系统 MUST 在搜索结果中返回该网页文档或其相关片段

### Requirement: 搜索结果携带网页来源信息
系统 MUST 在网页类型搜索结果中提供可供 UI 展示与范围联动的来源信息，至少包含：`title`（若可用）、`url`、`sourceType=web`，以及可关联到网页资料来源的稳定标识。

#### Scenario: 结果可区分网页资料来源
- **WHEN** 搜索结果包含网页类型文档
- **THEN** 每条网页结果 MUST 携带 sourceType=web、url 与对应网页资料来源标识，用于 UI 展示与范围关联

### Requirement: 支持按来源类型过滤搜索结果
系统 MUST 支持按来源类型过滤搜索结果，至少支持：仅文件、仅网页、全部。

#### Scenario: 仅查看网页结果
- **WHEN** 用户选择“仅网页”的过滤条件并执行搜索
- **THEN** 系统 MUST 仅返回 sourceType=web 的结果

### Requirement: 网页内容更新时索引可被刷新
系统 MUST 支持对同一网页资料来源再次抓取并刷新索引内容，并确保更新后的内容继续对应原有网页资料来源，参与后续搜索与范围选择。

#### Scenario: 刷新已有网页资料
- **WHEN** 用户对某个已存在的网页资料来源再次执行抓取并成功获取新内容
- **THEN** 系统 MUST 使用新的正文内容刷新该网页资料对应的索引，并使后续搜索与范围选择看到更新后的结果

### Requirement: 搜索模式支持按网页资料范围约束结果
系统 MUST 支持在搜索模式中将网页资料作为已准备范围参与过滤，并且仅返回属于已选网页资料范围的结果。

#### Scenario: 仅搜索某个网页资料
- **WHEN** 用户在搜索模式中选择某个网页资料作为范围并执行搜索
- **THEN** 系统 MUST 仅返回属于该网页资料来源的结果

### Requirement: 本地知识库搜索 MUST 可在统一会话工作台中执行
系统 MUST 允许用户在统一会话工作台中以 `纯搜索` 模式直接执行本地知识库搜索，而不需要跳转到独立搜索页面。

#### Scenario: 在统一工作台中发起纯搜索
- **WHEN** 用户在统一工作台切换到 `纯搜索` 模式并提交查询
- **THEN** 系统 MUST 在当前会话中返回该次搜索回合及对应检索结果

### Requirement: 纯搜索模式 MUST 只使用本地知识库检索链路
系统在 `纯搜索` 模式下 MUST 仅使用本地知识库的检索与结果展示能力，而 MUST NOT 调用 LLM 生成答案或依赖远端 AI 服务。

#### Scenario: 纯搜索模式不触发 AI 生成
- **WHEN** 用户在 `纯搜索` 模式提交查询
- **THEN** 系统 MUST 仅返回本地检索结果与固定摘要回复，而不会发起模型推理请求

### Requirement: 搜索范围在纯搜索模式下 MUST 作为严格过滤条件
系统在 `纯搜索` 模式下 MUST 将用户选定的资料范围解释为严格过滤条件；当某个本地范围尚未准备完成时，系统 MUST 不将其作为可检索候选内容。

#### Scenario: 已选范围仅检索已准备资料
- **WHEN** 用户在 `纯搜索` 模式选择若干已准备资料范围后提交查询
- **THEN** 系统 MUST 只在这些已准备范围内执行检索

#### Scenario: 未准备本地范围不会进入检索候选
- **WHEN** 用户尝试在 `纯搜索` 模式下使用尚未准备完成的本地范围
- **THEN** 系统 MUST 不将该范围纳入检索结果候选，并 MUST 明确提示该范围当前不可检索

### Requirement: 纯搜索结果 MUST 同时生成对话回合与检查器结果列表
系统在 `纯搜索` 模式下 MUST 同时生成当前会话中的搜索回合摘要，以及可在右侧检查器中浏览的结果列表、文档预览或网页打开入口。

#### Scenario: 搜索结果以对话和检查器双重形式呈现
- **WHEN** 一次纯搜索返回若干结果
- **THEN** 系统 MUST 在会话区显示该次搜索的固定回复摘要，并在右侧检查器展示对应结果列表和交互入口
