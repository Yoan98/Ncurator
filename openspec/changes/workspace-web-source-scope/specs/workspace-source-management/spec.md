## ADDED Requirements

### Requirement: 支持配置多个非嵌套工作空间
系统 MUST 允许用户配置多个本地工作空间，每个工作空间对应一个目录根路径，并且 MUST 阻止重复路径或嵌套路径同时存在于配置列表中。

#### Scenario: 添加有效工作空间
- **WHEN** 用户选择一个尚未配置且不与现有工作空间形成嵌套关系的本地目录
- **THEN** 系统 MUST 创建一个新的工作空间记录并保存该目录根路径

#### Scenario: 拒绝嵌套工作空间
- **WHEN** 用户尝试添加一个已经包含于现有工作空间中的目录，或尝试添加一个会包含现有工作空间的上级目录
- **THEN** 系统 MUST 拒绝该配置并提供可理解的提示，说明工作空间之间不能嵌套

### Requirement: 工作空间路径校验基于规范化后的真实路径
系统 MUST 基于规范化后的真实路径执行工作空间判重与嵌套校验，避免因路径表示差异、大小写差异或符号链接导致重复配置或边界失真。

#### Scenario: 通过不同路径表示选择同一目录
- **WHEN** 用户以不同但最终解析到同一目录的路径再次添加工作空间
- **THEN** 系统 MUST 将其识别为重复工作空间并拒绝添加

### Requirement: 持久化工作空间目录树快照
系统 MUST 为每个工作空间保存目录树快照，并且在 UI 中仅展示目录节点与当前支持的文件类型节点；首期支持的文件类型 MUST 至少包含 `pdf` 与 `docx`。

#### Scenario: 首次扫描工作空间
- **WHEN** 用户完成工作空间配置并触发首次扫描
- **THEN** 系统 MUST 保存该工作空间下的目录层级以及所有 `pdf`、`docx` 文件节点，并忽略其他不支持的文件类型

### Requirement: 支持按差异模式执行一键准备
系统 MUST 支持对单个工作空间执行一键准备，并在开始准备前提供差异模式选择，至少包含：全部差异、新增与删除、仅变更。

#### Scenario: 以全部差异模式执行准备
- **WHEN** 用户在某个工作空间上选择“一键准备”并选择“全部差异”模式
- **THEN** 系统 MUST 扫描该工作空间并处理新增文件、已删除文件与内容发生变化的文件

#### Scenario: 以仅变更模式执行准备
- **WHEN** 用户在某个工作空间上选择“一键准备”并选择“仅变更”模式
- **THEN** 系统 MUST 仅重新处理被判定为内容发生变化的文件，而不处理新增或已删除文件

### Requirement: 同一工作空间的准备任务具备明确生命周期
系统 MUST 为同一工作空间限定单个活跃准备任务，并在重复触发、部分失败与重试场景下提供一致、可理解的状态反馈；首期 MAY 不支持用户主动取消准备任务。

#### Scenario: 准备进行中再次触发一键准备
- **WHEN** 某个工作空间已经存在进行中的准备任务，用户再次触发一键准备
- **THEN** 系统 MUST 阻止创建并发准备任务，并提示当前任务仍在进行中

#### Scenario: 准备过程中部分文件失败
- **WHEN** 某个工作空间的一键准备完成，但其中部分文件准备失败
- **THEN** 系统 MUST 将工作空间标记为已完成本次准备流程，同时保留失败文件的节点状态与错误提示，以便后续重试

### Requirement: 明确展示准备状态、进度与帮助提示
系统 MUST 为工作空间和文件节点展示明确的准备状态，并在准备过程中展示阶段性进度；系统 MUST 为“工作空间”和“一键准备”提供简短、面向非技术用户的问号提示说明。

#### Scenario: 文件状态可区分
- **WHEN** 用户查看某个工作空间的目录树
- **THEN** 系统 MUST 能明显区分至少以下状态：未准备、准备中、已准备、需要更新、失败

#### Scenario: 准备过程中展示进度
- **WHEN** 某个工作空间正在执行一键准备
- **THEN** 系统 MUST 展示当前阶段与进度反馈，使用户能够理解系统正在扫描、比对或准备文件

### Requirement: 友好处理工作空间路径失效或文件缺失
系统 MUST 在工作空间根路径失效、子目录消失或文件已被删除/移动时，向用户提供友好的状态与后续操作提示，而不是仅暴露底层错误。

#### Scenario: 工作空间根路径已不存在
- **WHEN** 系统扫描某个工作空间时发现其根路径在本地已不存在或不可访问
- **THEN** 系统 MUST 将该工作空间标记为异常状态，并提示用户重新选择目录、重新扫描或移除该工作空间

#### Scenario: 已准备文件在本地被删除
- **WHEN** 系统扫描某个工作空间时发现某个已准备文件对应的原始路径已不存在
- **THEN** 系统 MUST 将该文件节点标记为缺失或待处理状态，并在后续准备中支持清理其对应的缓存结果
