## MODIFIED Requirements

### Requirement: 文档列表区分网页与文件类型
系统 MUST 将原有文档列表扩展为资料来源视图，并在该视图中区分展示工作空间资料与网页资料；在工作空间内部，系统 MUST 进一步区分目录节点与当前支持的文件类型节点。

#### Scenario: 资料来源页同时存在工作空间与网页资料
- **WHEN** 用户打开资料来源页，且系统中同时存在工作空间与网页资料
- **THEN** 系统 MUST 明确区分这两类来源，并在工作空间区域展示目录与支持文件节点，在网页资料区域展示网页条目

### Requirement: 网页类型文档展示标题与 URL
系统 MUST 在网页资料的列表项与详情信息中展示网页相关信息，至少包含：标题（若可用）与 URL。

#### Scenario: 展示网页资料来源信息
- **WHEN** 用户查看一个网页资料条目或其详情
- **THEN** 系统 MUST 展示该网页资料的 URL，且在可用时展示标题

### Requirement: 支持在 UI 上按类型筛选或聚合查看
系统 MUST 支持在资料来源视图中按来源类型筛选或聚合查看，至少支持：仅工作空间、仅网页资料、全部。

#### Scenario: 仅查看网页资料
- **WHEN** 用户在资料来源视图选择“仅网页资料”的过滤条件
- **THEN** 系统 MUST 仅展示网页资料相关的条目或分组

## ADDED Requirements

### Requirement: 工作空间文件显示准备状态与异常提示
系统 MUST 在工作空间树中为文件节点展示准备状态，并在节点失效、需要更新、准备失败时提供可理解的状态提示或操作入口。

#### Scenario: 文件需要更新
- **WHEN** 某个工作空间文件在最新扫描后被判定为内容发生变化
- **THEN** 系统 MUST 在该文件节点上展示“需要更新”或等价状态，使用户能够直观看到该文件需要重新准备
